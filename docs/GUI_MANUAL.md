# Nero Control GUI 사용 설명서

AgileX Nero 로봇팔을 마우스로 조작하는 화면입니다. CLI(`nero_cli.py`)와 **완전히 같은 명령 코어**를 사용하므로, GUI에서 저장한 웨이포인트·시퀀스를 CLI에서 그대로 쓸 수 있고 그 반대도 됩니다. GUI를 켜는 것만으로는 모터가 켜지거나 팔이 움직이지 않습니다.

---

## 1. 실행 방법

```bash
cd ~/dev/nero-control
./.venv/bin/python src/nero_ctrl/nero_gui.py --can can0 --fw v112
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--can` | `can0` | CAN 채널 이름 |
| `--fw` | `v112` | 펌웨어/파서 버전 (`auto`, `v111`, `v112`, `v120`) |
| `--speed` | `20` | 시작 시 이동 속도 % |

연결에 실패하면 창이 뜨지 않고 터미널에 원인이 출력됩니다.

---

## 2. 화면 구성

```
┌──────────────────────────────────────────────┐
│ 상태줄: linkage / ctrl / comm / fps / 속도    │
├───────────┬──────────────────────────────────┤
│ 현재 상태  │ 탭: 이동 | 웨이포인트 | 그리퍼 | 시퀀스 │
│ XYZ RPY   │                                  │
│ J1~J7     │                                  │
├───────────┴──────────────────────────────────┤
│ ●Follower ●Leader  티칭  CAN복귀   속도 [20]  │
├──────────────────────────────────────────────┤
│ 로그 창                                       │
│ nero> [명령 직접 입력]              [실행]     │
└──────────────────────────────────────────────┘
```

- **상태줄** — linkage 모드(FOLLOWER/LEADER), ctrl 모드, 통신 상태, fps, 현재 속도. 1.5초마다 자동 갱신됩니다.
- **현재 상태 패널(왼쪽)** — 플랜지 좌표(X·Y·Z mm, Roll·Pitch·Yaw deg)와 관절 J1~J7(deg) 실시간 표시. "지금 갱신"으로 즉시 갱신할 수 있습니다.
- **로그 창** — 모든 명령의 출력이 CLI와 동일한 형식으로 쌓입니다.
- **`nero>` 입력줄** — CLI 명령을 그대로 칠 수 있습니다 (`help`, `movep rel 0 0 -50` 등). 버튼에 없는 기능도 전부 여기서 가능합니다.

---

## 3. 색과 불빛 규칙

| 표시 | 의미 |
|---|---|
| 🔴 **빨간 버튼** | 누르면 팔이나 그리퍼가 **움직일 수 있는** 명령 |
| ⚪ 회색(기본) 버튼 | 읽기·저장 등 움직임 없는 명령 |
| 🟢 **초록 램프** | Follower/Leader 버튼 위의 동그란 불 — 현재 linkage 모드에 켜짐 |
| 회색 램프 | 해당 모드 아님 (둘 다 회색이면 모드를 읽지 못한 상태) |

### 모드에 따른 버튼 잠금

| 상태 | 이동·그리퍼·시퀀스 실행 버튼 | Leader 캡처 버튼 | 모드 전환 버튼 |
|---|---|---|---|
| FOLLOWER | 활성 | **비활성** | 활성 |
| LEADER | **비활성** (리더에선 이동 명령 불가) | 활성 | 활성 |
| 명령 실행 중 | 전부 비활성 | 비활성 | 비활성 |

### 확인 팝업

- 이동(movep/movel/movej/goto), 그리퍼 동작, 캘리브레이션, 티칭/CAN 전환, `seq run` → **예/아니오 팝업**이 뜹니다.
- **Follower/Leader 전환과 Leader 캡처는 팝업 없이 즉시 실행**됩니다. 리더 전환 시 브레이크가 풀려 팔이 손으로 움직이는 상태가 되므로, 누르기 전에 팔을 받치세요.
- 하단 모드 줄의 **"이동 경고문" 체크박스**(기본: 켜짐)를 끄면 위의 모든 확인 팝업 없이 명령이 즉시 실행됩니다. 단, 캘리브레이션의 "조를 손으로 닫고 확인" 팝업은 경고가 아니라 필수 절차라서 항상 뜹니다. 익숙한 작업을 반복할 때만 끄고, 평소에는 켜 두는 것을 권장합니다.

---

## 4. 하단 모드 줄

| 버튼 | 동작 |
|---|---|
| **Follower** | 일반 단일팔 제어 모드로 전환 (팔이 제어/홀드로 잡힘) |
| **Leader** | 무저항 드래그 모드 — 모터를 켜 브레이크를 풀고 손으로 움직이는 상태로 전환 |
| **티칭 (teach)** | 드래그 티칭 진입 (팝업 확인 후) |
| **CAN 복귀** | 티칭 종료, CAN 제어 복귀 (팝업 확인 후) |
| **이동 경고문** (체크박스) | 확인 팝업 켜기/끄기. 기본 켜짐 — 끄면 모든 이동 명령이 팝업 없이 즉시 실행 |
| **속도 % + 적용** | 이번 세션의 이동 속도(1~100%) 변경 |

## 5. 탭 설명

### 이동 탭
- **movep / movel (절대 위치)** — X·Y·Z(mm), R·P·Y(deg) 입력 후 "이동 (movep)" 또는 "직선 이동 (movel)". "현재 자세 채우기"를 누르면 지금 자세가 입력칸에 들어가므로, 일부만 고쳐서 움직이기 편합니다.
- **movep / movel rel (상대 이동)** — 지금 자세 기준 증분. R·P·Y를 0으로 두면 방향은 유지됩니다.
- movep와 movel의 차이: movep는 목표 자세까지 IK 경로(관절 보간)로, **movel은 플랜지가 직선 경로**로 이동합니다. movel은 경로 전체가 도달 가능해야 하므로 movep로는 되는 목표가 거부될 수 있습니다 — 그 경우 movep를 쓰세요.
- **movej / movej rel** — 관절 7개 절대각/증분각(deg). "현재 관절 채우기" 지원.

### 웨이포인트 탭
- 왼쪽 목록: 저장된 웨이포인트 (이름, 좌표, 관절각). 명령이 끝날 때마다 자동 갱신됩니다.
- **선택 지점으로 이동** — 목록에서 선택 후 이동. 방식은 `auto`(관절 우선)/`joints`/`cartesian`/`linear`. `linear`는 웨이포인트의 cartesian 자세까지 플랜지가 직선으로 이동합니다(경로 전체가 도달 가능해야 하며, `auto`가 자동으로 고르지는 않습니다).
- **저장 (save)** — 이름(필수)·설명(선택) 입력 후 현재 자세를 저장. **이미 있는 이름이면 저장하지 않고 중복 경고 팝업**이 뜹니다 (Leader 캡처도 동일). 단, `nero>` 입력줄로 직접 `save`를 치면 CLI와 같이 덮어씁니다.
- **Leader 캡처** — 아래 6장 참고.

### 그리퍼 탭
- **연결 확인 / 정보** — 읽기 전용 점검.
- **열기 / 닫기 / 목표 이동** — 힘(N)과 목표값(폭 mm 또는 각도 deg)을 지정해 구동. ⚠️ 이 펌웨어는 모터 enable이 전체 일괄이라 **팔 관절도 함께 켜지며 현재 자세로 홀드**됩니다.
- **캘리브레이션** — 영점 잡기. 그리퍼를 새로 장착했거나 전원을 껐다 켰으면 한 번 필요합니다. 팝업이 뜨면 **조(jaw)를 손으로 완전히 닫은 뒤** 확인을 누르세요. 스트로크(70/100mm)도 함께 저장할 수 있습니다.
- **리셋** — 그리퍼 비활성화 + 에러 클리어 (움직임 없음).

### 시퀀스 탭
- 목록에서 선택 후 **스텝 보기 / 실행**. 실행은 팝업 확인 한 번 뒤 모든 스텝이 **자동 확인으로 순차 실행**되며, 실패한 스텝에서 멈춥니다.
- **녹화** — 이름 입력 후 "녹화 시작"을 누르면, 이후 성공한 이동·그리퍼·sleep·속도 명령이 순서대로 기록됩니다(버튼 조작 포함). "녹화 저장"으로 저장, "녹화 취소"로 폐기. 저장 위치는 `src/data/sequences/`.

## 6. Leader 캡처 — 손으로 잡은 자세 저장하기

리더(드래그) 모드에서 팔을 손으로 원하는 자세에 놓고 웨이포인트로 저장하는 원버튼 워크플로우입니다.

1. **Leader** 버튼으로 리더 모드 진입 (팔을 받친 상태에서)
2. 팔을 손으로 원하는 자세로 이동
3. 웨이포인트 탭에서 **이름 입력** (설명은 선택)
4. **Leader 캡처** 버튼 클릭 → 자동으로 `follower 전환 → 저장 → leader 복귀` 실행
5. 팔이 다시 드래그 상태가 되면 다음 자세를 잡고 3~4 반복

주의사항:
- 버튼은 **LEADER 모드일 때만 활성화**됩니다.
- follower 전환 순간 팔이 제어/홀드로 잡히고, 끝나면 다시 브레이크가 풀립니다. **시작과 끝 모두 팔을 받칠 준비**를 하세요.
- 중간 단계가 실패하면 그 자리에서 멈추고 **리더로 자동 복귀하지 않습니다** (팔은 follower/홀드 상태로 안전하게 남음). 로그 확인 후 필요하면 Leader 버튼으로 직접 복귀하세요.

---

## 7. 안전 동작 정리

- 움직이는 명령은 한 번에 하나씩만 실행됩니다 (실행 중에는 모든 버튼 잠김).
- 리더 모드에서는 이동 명령이 코어 단계에서도 거부됩니다 (버튼 잠금은 이를 미리 보여주는 것).
- 창을 닫아도 **모터는 그대로** — 팔은 마지막 자세를 유지합니다 (CLI의 `quit`과 동일).
- 명령 실행 중에 창을 닫으려 하면 한 번 더 물어봅니다.
- 저장 안 한 시퀀스 녹화는 종료 시 폐기됩니다.

## 8. 자주 겪는 상황

| 증상 | 원인 / 해결 |
|---|---|
| 램프가 둘 다 회색, 좌표가 `—` | 모드/자세 피드백을 못 읽는 상태. CAN 연결과 팔 전원 확인 후 "지금 갱신" |
| 이동 버튼이 눌리지 않음 | LEADER 모드이거나 다른 명령 실행 중. Follower로 전환하거나 완료 대기 |
| Leader 캡처가 눌리지 않음 | FOLLOWER 모드이거나 모드를 못 읽은 상태. Leader 진입 후 사용 |
| 그리퍼가 명령에 반응 없음 | 캘리브레이션(영점) 미실시 가능성 → 그리퍼 탭에서 캘리브레이션 |
| `[movep] NOT reachable` | IK로 도달 불가한 목표. 좌표를 현재 자세 근처로 수정 |
| `[movel] NOT reachable` | 직선 경로 전체가 도달 가능해야 함. movep로 시도하거나 목표를 가깝게 수정 |
| 이동이 timeout | 팔 상태 확인. 도달 확인만 실패한 것일 수 있으니 좌표 재확인 |
